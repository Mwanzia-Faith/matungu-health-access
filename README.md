# Healthcare Accessibility in Matungu Sub-County, Kenya

**Status:** In progress

## Problem
Which communities in Matungu Sub-County are far from a health facility,
and where would a new or upgraded facility help the most people?

## Objectives
1. Reproduce my final year thesis buffer and network analysis in Python.
2. Compare buffer and road-network coverage at 1, 3 and 5 km.
3. Identify the top 5 underserved areas and publish an interactive map.
